## General info

This project is created to test the API for the service ["DOSKA"](https://qa-desk.stand.praktikum-services.ru/).


## 'api' directory
You can find api methods for related endpoints ['api'](../blob/main/api) directory

### 1. listing_api
Includes api methods for endpoints related to the 'Listing' object.

### 2. user_api
Includes api methods for endpoints related to the 'User' object.

## Test files
You can find all files with the tests for specific page in ['tests'](../blob/main/tests) directory.

### 1. 'test_listing' files
Each file includes the set of tests for each 'Listing' endpoint: creation, editing, deletion.

### 2. 'test_user' files
Each file includes the set of tests for each 'User' endpoint: signup, signin.

## Additional files
